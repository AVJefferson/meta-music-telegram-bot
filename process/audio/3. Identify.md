## Song Tagging

Song tagging is done using information from sources:

1. ID3 tags already present in the file.
2. AcousticId API
3. MusicBrainz API
4. Last.fm API

## Song Match/Mismatch

1. If song details match, set the card contents to the song details.
2. If song details do not match, ask user to pick the correct song from possible matches.

```markdown
AcousticId: <AcousticId> (Link to AcousticId song page)
Song Matches: <Song Matches>

Unable to pinpoint the song. Please pick the correct song from the possible matches.
Buttons: Album - Artist - Song Title(One for each possible match)
Buttons: Confirm | Cancel | Pagination buttons
```

**Button Action**: Album - Artist - Song Title button will select that song
**Button Action**: Confirm button will confirm the song selection
**Button Action**: Cancel button will cancel the process and delete the song card message.
**Button Action**: Pagination buttons will navigate through the possible matches

3. Once user picks the correct song, check if id3 tags are all equal. If identical, use it.
4. If any id3 tag is different, ask user to pick the correct id3 tag OR enter the correct id3 tag.

```markdown
Title: ~<Song Title from file>~ -> <Song Title correction>
Track Number: ~<Track Number from file>~ -> <Track Number correction>
Disc Number: ~<Disc Number from file>~ -> <Disc Number correction>
Album: ~<Album from file>~ -> <Album correction>
Artist: ~<Artist from file>~ -> <Artist correction>
Album Artist: ~<Album Artist from file>~ -> <Album Artist correction>
Composers: ~<Composers from file>~ -> <Composers correction>
Year: ~<Year from file>~ -> <Year correction>
Genre: ~<Genre from file>~ -> <Genre correction>
```

5. Once user picks the correct id3 tag or enters the correct id3 tag, use it.

## Caviats

1. If lyrics is not synced, show first 3 Non-empty lines, without timestamps. (if available)
2. If corrections are made from original file, then strike through the original value.
3. Song card messages are removed when identifying stage ends.
4. Only one song per chat_id is allowed to be edited by the user at a time during the identifying stage.
5. If multiple songs are sent in the same chat_id, start identifying all songs one by one; but if conflicts arise, queue the conflicting song user selections one by one.
6. If multiple songs are sent, keep the pace as set by rate limiting. If rate limiting exceeds limit, wait for rate limiting to reset to continue identifying songs automatically.

## ID3 Tag Correction Formats

### Title

Title should not have (Original Soundtrack from the Movie) in the title. Movie name should be present in the album name.

### Track Number, Disc Number

If track number is not present, set it to 1.
If disc number is not present, set it to 1.

### Album

### Artist, Album Artist, Composers

Format: "Artist 1, Artist 2 & Artist 3 Ft. Artist 4, Artist 5 & Artist 6"

Artists should be sorted by Album Artist first, then the other artists in alphabetical order.
Composers should be sorted by Album Artist first, then the other composers in alphabetical order.

### Genre

Format: "Language | Genre 1 | Genre 2 | Mood 1 | Mood 2 | Instrument 1 | Instrument 2"

#### Language

If song has more than one language, Ask user to pick the primary language. Primary language should be the first in the list.
