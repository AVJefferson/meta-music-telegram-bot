# Step 4: Album Art

## Song Card Markdown

```markdown
SONG CARD MARKDOWN

_Pick Album Cover_
Buttons: Confirm | Cancel
Buttons : <Source> (<Size>) for each source
```

## Example

```markdown
_Teardrop_
Album: Mezzanine
Artist: Massive Attack
Album Artist: Massive Attack
Composers: Massive Attack
Year: 1998
Genre: Trip-hop | electronic
Lyrics:
01:00 Love, Love is a verb
01:05 Love is a doing word
1:09 Fearless on my breath
FLAC | 04:50 | 34.30MB | 86kbps | 44.1KHz | 16bit | 2CH

_Pick Album Cover_
Buttons: File (<1200x1200>) | Last.fm (<1200x1200>) | CCA (<1200x1200>) | Discogs (<1200x1200>) | ITunes (<1200x1200>) | Cancel
```

## Caviats

1. If a source does not have album art, do not show it and adjust numbering.
2. If multiple sources have the same album art, use "2. Source 1 = Source 2 = Source 3 (1200x1200)" and adjust numbering.
3. Each Album art image should have a caption of source name and size.
4. If albumart exists in the song folder already, reuse that albumart image and skip the albumart selection process.
5. Once the Song card is formed, all messages are always below it or as separate messages, if any.
