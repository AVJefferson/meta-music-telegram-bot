# Step 5: Upload

## Song Card Markdown

```markdown
SONG CARD MARKDOWN ONLY
```

## If User has no Cloud Storage.

Just update the file in the song card in the same chat_id. Also update the albumart, song title, artist so that telegram can show the correct song information.

## If User has Cloud Storage.

1. Check if telegram file should be corrected. if yes, update the file in the song card in the same chat_id. Also update the albumart, song title, artist so that telegram can show the correct song information. If no, ignore. If ask each time, then this is a question.
2. If autoforward is on, forward the final card (with song file) to the chat_id(s)
3. If user preference for fileformat is enabled, continue. Else ignore.
4. Check user preferences for cloud storage location. If none, ignore. If Library, auto upload to library folder. If review, auto upload to review folder. If ask each time, then this is a question. If none, then ignore.
5. If delete original file is Yes, delete the file if possible. if its ask each time, then its a question.
6. If there are questions, then send a new message with the questions and buttons for choices - one for each question. use then toggles between choices and then clicks confirm.

## Caviats

1. If command is invoked in group, the response message will be sent as ephemeral.
2. If command is invoked in the same chat as autoforward, autoforward will not be triggered for that chatId again.
