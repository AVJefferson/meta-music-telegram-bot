# Step 1: Download

## Song Card Markdown

```markdown
...Downloading <song_file_name> (<progress_percentage>%)
```

## Example

```markdown
...Downloading Attack - Teardrop.flac (10%)
```

## Caviats

1. Progress percentage is calculated based on the file size and the amount of data downloaded.
2. Progress percentage is updated every 5 second or every 25% of the file size, whichever is longer.

## No Notifications

1. If song is deleted while downloading, send notification to user as "Song deleted while downloading". This is error. Cancel the download.
