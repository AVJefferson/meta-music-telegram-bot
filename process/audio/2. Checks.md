# Step 2: Checks

## Song Card Markdown

```markdown
...Going through this song file
```

If any of the checks fail, set the card contents to the error message.

## File Format Check

Check if the file format is ANY of the supported music file formats.

```markdown
File format not supported
```

## File Size Check

Check if file is not too large. App allows only X Mb for a single file by default. X Modifiable by admin using mini app admin settings. Default value is set by environment variable. DO NOT DOWNLOAD THE FILE IF IT IS TOO LARGE.

```markdown
File is too large
```

## File Corruption Check

Check if file is not corrupted.

```markdown
File is corrupted
```

## File Deduplication Check

Check if the file SHA-256 hash is already present locally or in the user cloud (same user). If it is, get details of that song using the song log file and skip 3. Identify step. Skip 4. Album art step if albumart is available in the song folder.
