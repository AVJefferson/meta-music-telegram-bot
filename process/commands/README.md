## Scope

- **Direct messages:** Command available in direct messages.
- **Group chats:** Command available in group chats.
- **Group Administrators:** Command available only to group administrators.
- **Ephemeral:** Command is ephemeral. The chat is hidden from the other users.
- **Admin:** Command is available only to admin user id set in the environment variable.

## Command Details

- **Command:** The command name.
- **Description:** The description of the command.
- **Usage:** The usage of the command.
- **Scope:** The scope of the command.
- **Response:** The response of the command.
- **Example:** The example of the command responses.
- **Caviats:** The caviats of the command.
- **No Notifications:** There are no notifications for the command. This is used when the command does not send any notifications to the user or admin.
- **Notifications:** The notifications of the command.
